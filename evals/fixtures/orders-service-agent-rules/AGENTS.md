# Repository instructions

## Owner rules

The owner asked for these rules.

- Every change ends as one clean local commit on the current branch, with a message that says what changed and why. Do not push; the owner delivers.

## Rules added by agent sessions

An agent session added this rule on its own judgment after an earlier fix. The owner did not ask for it.

- Every fix adds a new regression test file under tests/ and an entry in docs/fix-log.md that describes the fix.
