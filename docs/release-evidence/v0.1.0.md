## Replay the bundled validators

The bundled skill and plugin validators are Codex prerequisites, not project dependencies. Create a fresh Python environment, install `requirements-dev.txt`, then locate the `skill-creator` and `plugin-creator` skill roots in the installed Codex skill catalog. Do not set `HOME` or `CODEX_HOME` to run these commands.

On a standard local Codex installation, the catalog is relative to its configured home:

```sh
catalog_root="${CODEX_HOME:-$HOME/.codex}/skills/.system"
skill_creator_root="$catalog_root/skill-creator"
plugin_creator_root="$catalog_root/plugin-creator"

test -f "$skill_creator_root/scripts/quick_validate.py"
test -f "$plugin_creator_root/scripts/validate_plugin.py"
python "$skill_creator_root/scripts/quick_validate.py" skills/cto-run
python "$plugin_creator_root/scripts/validate_plugin.py" .
```

For a managed Codex runtime, locate the installed skills named `skill-creator` and `plugin-creator` in that runtime's skill catalog, then use the same paths relative to each skill root. Both scripts require PyYAML, which the fresh environment receives through `requirements-dev.txt`.

The local-scope marketplace inventory is useful, but it is not an installation result.
