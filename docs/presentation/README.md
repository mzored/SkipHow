# Presentation explainer

[`skiphow-explainer.html`](skiphow-explainer.html) is a standalone Russian-language presentation aid for explaining SkipHow to product owners and technical audiences.

It covers the responsibility contract, package shape, real request examples, authority branches, verification loops, optional parallel work, and host boundaries. The technical diagrams distinguish SkipHow's instruction contract from capabilities supplied by Codex or Claude Code. Claims follow the repository README, design record, and evidence record; unverified behavior is labelled in the visual.

Open the HTML file directly in a browser. It needs no project build step and the presentation itself makes no data requests.
