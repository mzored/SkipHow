# Delivery handoff

Accept a clear brief directly. Ordinary requested changes need no prior Product Contract, tracker item, product review, or approval.

For tracked work, read its canonical item and governing decision. Otherwise keep the brief in context. Load a tracker only when it owns the request or repository policy requires it.

Pass outcome, behavior, constraints, evidence, target, and any extended decision to `../cto/SKILL.md`. It chooses execution shape after inspection.

Use `references/delivery-runbook.md` only for a selected campaign. Bulk selection and run resume are internal and never pull new work into an active campaign.
