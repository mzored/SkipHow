# Delivery handoff

Accept a clear lightweight delivery brief directly from the router. A prior Product Contract, tracker item, product review, or Owner approval is not required for an ordinary requested change.

For existing tracked work, read the canonical item and its exact governing decision. For an untracked request, keep the brief in working context. Read a tracker only when it owns the request or repository policy requires lifecycle updates.

Pass the outcome, required behavior, non-goals, acceptance evidence, repository target, and any applicable extended decision to `../cto/SKILL.md`. The technical controller chooses normal execution, temporary diagnosis, or a durable campaign after inspection.

Use `references/delivery-runbook.md` only when the controller selects a campaign. Queue draining, bulk ready-item selection, and explicit run-directory resume are advanced internal operations. They do not change the normal conversational path and never pull newly approved work into an active campaign.
